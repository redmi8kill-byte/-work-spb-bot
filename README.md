# Работа в Питере — Telegram Mini App

Готовый Telegram Mini App для размещения вакансий.

## В комплекте
- `main.py` — FastAPI-приложение, Telegram webhook, Mini App, админка, пользователи и заказы.
- `requirements.txt` — зависимости.

## Что есть в этой версии
- Неоновый premium/cyberpunk дизайн в стиле Санкт-Петербурга.
- Главная: профиль, статистика, поиск, популярные тарифы, канал и последние заказы.
- Тарифы и пакеты в обновлённом glass/neon интерфейсе.
- Корзина с промокодом, итогом и кнопкой оплаты.
- Профиль с заказами, каналом и поддержкой.
- Скрытая админка внутри Mini App только для администратора.
- Раздел пользователей.
- Telegram-канал: https://t.me/worksaintpeterburg
- Поддержка: https://t.me/RZTFrong
- Заявки уходят администратору в Telegram.
- WEBPAY можно подключить после подтверждения провайдера.

## Запуск
```bash
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port 8080
```

Переменные окружения: `BOT_TOKEN`, `WEBAPP_URL`.
