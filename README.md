# Работа в Питере — Mini App

Версия включает колесо удачи, инвентарь призов и рассылку администратора.

## Рассылка

Администратор может отправить всем пользователям:

- `/broadcast текст` — текстовая рассылка;
- фото с подписью `/broadcast текст` — фото + подпись.

К обеим рассылкам автоматически добавляется кнопка **🎡 Открыть колесо**, которая открывает Mini App внутри Telegram.

Для фото команда должна находиться именно в **подписи к фотографии**.

## Колесо

5 визуальных секторов:
- 😄 Попробуй завтра
- 🎟️ −10% скидка
- 🎁 −20% скидка
- ⭐ Бонус к заказу
- 🆓 Бесплатное размещение

Серверные вероятности: 50% / 20% / 15% / 10% / 5%. Проценты пользователю не показываются.

## Инвентарь

Выигранные призы сохраняются в «Мои выигрыши». Для приза можно получить код активации.

## Запуск

```bash
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port 8000
```
