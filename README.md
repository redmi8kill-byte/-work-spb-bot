# Работа в Питере — Telegram Mini App

Готовый FastAPI-проект для Telegram Mini App сервиса размещения вакансий в Санкт-Петербурге.

## Что внутри
- текущий тёмный дизайн Mini App;
- тарифы и пакеты;
- корзина и оформление заявки;
- профиль и поддержка;
- официальный Telegram-канал: https://t.me/worksaintpeterburg;
- колесо удачи в стиле SPB/золото/фиолетовый;
- 1 бесплатная попытка колеса в сутки;
- после бесплатной попытки вращение стоит 5 ⭐;
- внутренний баланс ⭐ для платных вращений;
- пополнение внутреннего баланса через нативную оплату Telegram Stars (XTR);
- серверное определение результата и защита от повторного списания оплаты;
- скрытая админка внутри Mini App только для Telegram-администратора;
- статистика, заказы и пользователи;
- Telegram webhook и уведомления админу;
- SQLite.

## Важно про Stars
Баланс ⭐ в приложении — это внутренние кредиты сервиса. Пользователь пополняет его реальными Telegram Stars через окно оплаты Telegram. Для цифровых услуг Telegram требует использовать Stars (XTR).

Пакеты пополнения: 25 ⭐, 50 ⭐ и 100 ⭐. Одно платное вращение = 5 ⭐.

Шансы колеса задаются на сервере:
- 50% — «Попробуй завтра»;
- 20% — скидка 10%;
- 15% — скидка 20%;
- 10% — бонус к заказу;
- 5% — бесплатное размещение.

В админке Mini App добавлен блок «💰 Доход / Stars»: реальный баланс Stars бота берётся через Telegram Bot API, а также показываются полученные через приложение Stars, сумма за сегодня и количество платежей.

## Запуск
```bash
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port $PORT
```

Для Railway нужны переменные:
- `BOT_TOKEN`
- `PUBLIC_URL`
- `ADMIN_SETUP_CODE`

Для платежей Stars отдельный платёжный provider token не нужен: для цифровых товаров используется валюта `XTR` и пустой `provider_token`.

Команда поддержки оплаты: `/paysupport`.


## 📣 Рассылка

Администратор может отправить сообщение всем пользователям, которые запускали бота через `/start`, командой:

`/broadcast текст сообщения`

Например:
`/broadcast 🎡 Колесо удачи уже доступно! Заходи в мини-приложение и попробуй выиграть приз 🎁`

Команда доступна только привязанному администратору. Бот отправляет сообщения последовательно и показывает итог: сколько доставлено и сколько не доставлено. Пользователи, которые заблокировали бота или недоступны, могут не получить сообщение.
